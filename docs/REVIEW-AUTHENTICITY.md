# 真实性深度审计·第三部分（以"非医疗人士/高考生体验真实医疗环境"为宗旨）

> 生成：2026-08-01 · 依据用户明确的游戏目的：让非医疗专业人员与高考学生体验**真实的医疗环境**。
> 方法：逐关键词统计事件池覆盖 + 关键流程缺口核对 + 已验证真实项确认。
> 前两部分见 `docs/OPTIMIZATION-ROADMAP.md`、`docs/REVIEW-PLAYABILITY.md`。

---

## 一、核心判断

游戏当前很好地呈现了医生职业的**"苦"**（夜班、手术、纠纷、低收入、心理压力、亚专科劳累），
诊断工具和用药管理仍明显偏薄；知情同意、患者随访回声、病历证据链及纠纷调解已补入。
对非医疗人士而言，"医生每天如何诊断和管理治疗"仍是当前教育价值的最大缺口。

---

## 二、医疗流程真实度缺口（事件池关键词统计）

| 医疗现实（非医疗人士最该知道） | 事件池覆盖 | 判断 |

## 三、按"真实医疗环境"维度逐项审计

### 3.1 诊疗全流程（就诊 → 诊断 → 治疗 → 随访）
- **现状**：有门诊/查房/手术/抢救片段；缺诊断思维（鉴别诊断、检验影像、病理）。
- **任务**：
  - [ ] **P0** 新增"诊断"类事件：化验/影像/病理报告解读、鉴别诊断讨论（高知识/临床要求）、开检查单
  - [x] **P0** 新增"知情同意"事件：术前谈话签字，并按沟通质量进入两条纠纷回响
  - [ ] **P1** 新增"用药管理"事件：抗生素规范/处方药/配伍禁忌/不良反应（临床力+知识考核）
  - [x] **P1** 新增"随访/复查"事件：`patientEchoEvent` 仅在认真管理过对应患者后解锁复诊/感谢/投诉

### 3.2 医学知识准确性（教育价值根基）
- **抽查**：CPR "一百到一百二"（100-120/分）✅；心电图拉直✅；心梗突发✅——抽查内容准确。
- **风险**：生成事件（eventGen 模板）的医学内容未系统审计，可能有术语错误。
- **任务**：
  - [x] **P1** 建立医学事实审计清单框架（`MEDICAL-FACT-AUDIT.md`）
  - [ ] 按清单逐条对照权威来源完成医学事实复核；当前不能宣称已认证
  - [ ] 生成事件模板的医学术语统一规范（当前 `patient/mood/complaint` 模板较抽象）

### 3.3 医生工作的"流程现实"
- **现状**：病历/交班/医嘱有；**缺**：排班制度（门诊/夜班/手术轮转）、医疗文书（入院记录、病程、会诊单）、分级查房（主任-主治-住院医）、带教查房。
- **任务**：
  - [ ] **P1** 增加"排班/轮转"机制叙事（外科手术日 vs 内科查房日 vs 门诊日）
  - [ ] 增加"分级查房被提问"事件（教学查房，主治/主任连环提问，答不上来丢脸但学得多）
  - [ ] 增加"医疗文书"细节（病历质量→已接进诉讼/扣费，可再扩展"病程记录/会诊单"）

### 3.4 医院生态（非医疗人士最陌生）
- **现状**：医患纠纷/医保拒付/DRG/行政有；护患协作及医务科/医患办调解已有事件；
  科室间利益、进修/学术会议、医联体/社区转诊仍薄弱。
- **任务**：
  - [x] **P1** 增加护患/医护协作事件（医嘱复核、护士长照拂、家属冲突协作）
  - [x] 增加医患办调解和医疗损害鉴定流程（分科诉讼两轮节点）
  - [ ] 增加"进修/学术会议"（医生成长的现实路径，含经济成本）

### 3.5 学生视角的升学与入门现实
- **现状**：高考→选校→本科→规培链路完整；**缺**：医学院生活的具体"吓人"细节（解剖课、标本、医学生作息、期末考）。
- **任务**：
  - [x] **P1** 增加解剖课与致敬大体老师事件
  - [x] 增加医学生期末周、通宵与背书压力事件

### 3.6 经济真实性（已核对的现实数据）
- 规培补助 4200/季（1400/月）、学硕 3600/季（1200/月）——**现实规培 2-5k/月**，偏低端但合理。
- 职业收入：主治 ~14.6万/年、正高 ~17.6万/年——**低于年薪制口径**（主任 30万+/年），需上修（前文 R4/R18 已列，此处确认 P0）。
- **任务**：见 OPTIMIZATION-ROADMAP R2/R4，不再重复。

### 3.7 职业风险现实（教育价值高）
- **现状**：纠纷/诉讼/医保拒付/职业暴露已覆盖主要风险；四个亚专科诉讼分别呈现漏诊、
  术后并发症、产科急症与儿科病情进展，仍可继续补非诉讼型长期转归。
- **任务**：
  - [x] 增加内科漏诊争议与患者后续损害事件
  - [x] 增加外科并发症、产科急症和儿科不良转归事件

## 四、为"非医疗人士体验"的教育增强建议

1. **开局"医学名词表"**：H 帮助页或图鉴增加"医学小百科"——非医疗玩家遇到的专业词（DRG/知情同意/副高/规培/医保）可随时查
2. **结局教育卡增强**：结局页保留本局数据与模拟参照；如需增加现实写照，必须先通过 evidence gate 和真人来源复核
3. **医学院第一课引导**：本科第一章给"医学生的一天"（解剖/背书/实验/见习）的真实节奏，建立沉浸
4. **错误科普零容忍**：医学事实审计优先（3.2），面向学生的内容不能有硬伤
