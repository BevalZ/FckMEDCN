# 医学事实审计清单

> 目的：为面向高中生与非医疗人士的内容建立可追踪的医学事实复核记录。
> 本清单记录“需要核对什么”，不把静态代码检查当作临床事实认证。
>
> 状态：`待核对` / `已核对` / `需修改`。完成复核时填写审阅人、日期、依据与修改提交。

## 复核规则

- [ ] 疾病、症状、检查和治疗的组合符合常见临床语境，未把筛查、诊断、治疗混为一谈。
- [ ] 急症叙事包含合理的先后顺序：生命体征/分诊、必要检查、上级或专科协作、处置与观察。
- [ ] 药物内容不暗示玩家可自行处方；抗菌药、抗凝药、镇静药和急救药需特别复核适应证、禁忌证与风险表述。
- [ ] 儿童、孕产妇、老年人和沟通障碍患者的描述符合相应人群特点，不使用污名化或绝对化表述。
- [ ] “约复查”“转诊”“签字”“医保”等流程描述与当地医院实际流程的差异已注明或保持足够概括。
- [ ] 小游戏题目只考稳定、基础且不易误导的常识；存在地区指南差异时不写成唯一答案。
- [ ] 审计不替代医生、药师或医学教育者的最终审核。
