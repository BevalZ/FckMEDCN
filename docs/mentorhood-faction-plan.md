# 导师招生与自有势力系统方案

## 设计目标

玩家在职业后期不再只是被导师、医院和派系选择的人，也会逐渐成为能选择学生、分配资源、塑造团队风格的人。这个系统要表达三件事：

- 成为导师必须有现实门槛，通常在副高以后才可能获得稳定招生资格。
- 招生不是单纯加学生数量，而是分数、排名、导师名额、熟人托付、科室资源和面试判断共同作用。
- 自己的势力既可以是稳定传承，也可能演变成山头、保护伞、署名纠纷和学生背叛。

## 触发阶段

导师招生不得出现在本科、规培、硕博在读或求职阶段。可触发阶段限定为：

- `career`：已经通过副高或同等资质后，开放第一个招生名额。
- `pinnacle`：拥有多个学生、进修医生、年轻同事和合作资源后，形成梯队。
- `retirement`：学生和旧团队以回声事件形式出现，评价玩家怎样使用过权力。

核心门槛：

- `passed_fugao`：获得招生名额的最低现实门槛。
- `own_faction`：已经建立自己的导师组或稳定小团队。
- `has_students` / `mentored`：带过学生，后续可以触发学生论文、被挖走、退休送别。

## 招生流程

招生名额首次出现时，玩家可以选择团队定位：

- 临床教学组：床旁能力、病历质量、告知沟通、出科评价更重要；学生忠诚较高，但科研产出慢。
- 科研/转化小组：课题、文章、基金和实验平台更重要；科研声誉提升更快，但体力和金钱成本更高。
- 暂缓招生：避免把学生卷入混乱，短期压力下降，但错过梯队窗口。

后续招生面试要体现现实排序：

- 高分高排名学生：分数和面试表现强，关系成本低，忠诚和可塑性较好。
- 熟人托付学生：进入门槛带有人情，初始忠诚较低，背叛风险和派系债更高。
- 资源交换名额：玩家没有直接新增学生，但派系忠诚和未来会议筹码增加。

## 学生类型

学生以持久状态记录在 `colleagues.students` 中，而不是只用 flag 记录。

- `protege`：真徒弟型。忠诚较高，成长慢但长期回声强。被外院挖走时可以选择放手合作或强行留下。
- `utilitarian`：互相利用型。人情、名额和资源交换进入组内，短期关系收益高，但背叛风险高。
- `spy`：竞争阵营渗透或双边站队型。当前版本预留类型，后续可用于科室斗争、项目评审和学科方向争夺。

每个学生记录：

- `id` / `name`：用于后续回声和点名。
- `type`：决定忠诚与背叛风险基线。
- `loyalty`：受组会管理、署名伦理、职业机会影响。
- `betrayalRisk`：受派系对立、人情招生、压榨式管理和学术不端影响。
- `status`：后续可扩展为毕业、疏远、背叛。

## 自有势力

玩家建立自己的导师组后，`mentorFaction.faction` 记录团队名称、类型、等级和资源结构：

- `academic`：论文、基金、转化项目、学术会议话语权。
- `clinical`：床位、亚专科、手术量、教学病例和规培评价。
- `administrative`：科室排班、职称推荐、评审席位、流程资源。

势力等级由资源强度和声誉共同决定：

- `fringe`：有名义团队，但资源不稳定。
- `member`：有学生和固定方向。
- `core`：能影响科室分配和学科方向。
- `leader`：能招生、推荐、分配平台，并在退休后留下明确传承。

## 关键事件链

当前实现事件：

- `mentorhood_quota_notice`：第一个招生名额，建立临床组或科研组。
- `mentorhood_interview_list`：招生面试名单，处理排名、人情和资源交换。
- `mentorhood_group_meeting`：第一次自己的组会，决定团队文化。
- `mentorhood_student_paper`：学生第一篇论文，处理署名伦理和包装风险。
- `mentorhood_student_poached`：学生被外院挖走，考验势力是否靠自由合作维持。
- `mentorhood_student_betrayal`：人情学生或功利学生把旧账递出去。
- `mentorhood_own_school`：形成自己的梯队和学科势力。
- `mentorhood_retirement_students`：退休期学生回声。

## 与已有系统联动

导师招生系统需要和以下系统保持一致：

- 科研系统：学生论文、基金项目、学术不端风险。
- 同事系统：学生忠诚、同侪嫉妒、团队支持。
- 导师/派系系统：派系忠诚、声誉、竞争强度。
- 终局系统：传承、树、回忆录、学生送别。
- NPC 系统：后续可把学生做成可行走 NPC，并在职业、巅峰、退休阶段再次出现。

## 回归测试清单

- 没有 `passed_fugao` 时不能触发第一个招生名额。
- 通过副高后，在 `career` / `pinnacle` 才能触发招生名额。
- 建组后必须写入 `mentorFaction.faction`，并设置 `own_faction`。
- 招到学生后必须写入 `colleagues.students`，并设置 `mentored` / `has_students`。
- 招生面试应在建组后开放。
- 功利型学生应带来更高背叛风险，并能开启后续旧账事件。
- 学生被挖走和自己的梯队只能在后期出现。
- 退休期能看到带过学生的回声。
- 新增 flag 必须有后续消费，不能只设置不回响。
