# 医学生升学与分流路线改造方案

## 目标

把普通五年制、5+3、八年制、保研、考研、考博、规培和求职拆成有时间锚点、有门槛、有失败出口的链路。重点避免“大一大二考研”“硕士毕业自动读博”“失败后没有退路”等事件错误。

## 时间轴约定

本科阶段共 20 季，按五年制医学生处理：

- `0-3`：大一，只能出现入门、适应、英语启蒙、基础课压力。
- `4-7`：大二，可出现四六级、方向认知、科研启蒙，不能出现正式考研。
- `8-11`：大三，可出现早临床、科研/绩点积累、保研准备。
- `12-15`：大四，推免排名、公示、考研报名、择校择专科。
- `16-19`：大五，考研初试、出分、复试、调剂、失败后的规培/求职/二战。

硕士阶段共 12 季：

- `0-3`：入学、导师磨合、课题启动。
- `4-7`：文章、课题、临床/科研方向压力。
- `8-11`：博士申请窗口、联系导师、材料审核、英语/专业面试、排名候补。

## 本科升学规则

早期只能做准备，不直接决定结果：

- 英语四六级在大一/大二出现，`passed_cet6` 作为复试英语、考博英语问答的帮助。
- 大二的“5+3 与四证合一”只能改成方向认知，不能直接进入考研考场。
- 大三可以出现科研经历、绩点焦虑、保研准备，但不能宣布正式上岸。

推免：

- 大四上以后进入推免排名竞争。
- 推免结果需要知识/绩点足够高，或承担灰色人情风险。
- 推免成功设置 `baoyan` 与科研轨 `track_research`，本科结束后进入硕士。
- 推免失败会落到考研准备，而不是原地消失。

考研：

- 大四下到大五上出现择校择专业、报名、专业课/英语/政治准备。
- 同一批报考同一医院同一专业需要比较分数和排名，不能只有“过线/不过线”。
- 初试通过后还要复试。复试问题包括：
  - 为什么学医、为什么这个专业。
  - 为什么报本院/本导师。
  - 对科研/临床规划的理解。
  - 临床病例或专业基础题。
  - 英文自我介绍、英文摘要翻译或文献问题。
- 六级通过提供英语复试更稳的选项；没有六级可走中文专业问题硬扛，但概率更低。
- 成功设置 `kaoyan` 和 `track_research`，本科结束后进入硕士。
- 失败出口包括调剂、直接规培/求职、二战。
- 二战提高知识但降低面试叙事稳定性，设置 `kaoyan_repeater`，后续面试里出现“空档一年”的压力。

## 硕士考博规则

考博不是单个“考/不考”事件，而是申请制链：

- 硕士后期先选择医院/导师组合：
  - 顶级附属医院/强导师：平台强，但材料和面试更卷。
  - 同校导师/熟人组：推荐信、熟悉度有优势。
  - 地方强科：竞争略低，更看临床与稳定性。
- 联系导师会影响关系和材料机会。导师推荐、同校、已发表论文、科研能力、六级/英语均影响后续。
- 材料审核包括论文、课题、硕士导师推荐、排名、同批报考人数。
- 面试包含研究计划答辩、专业追问、英语文献问答。
- 可选择“请导师打招呼”。它给面试/材料加成，但降低 reputation 或增加关系债，作为隐性因素暗含，不做成正向爽点。
- 最终有录取、候补、失败三类。
- 录取设置 `phd_admitted`/`will_phd`，硕士毕业进入博士。
- 候补可等待或先找工作；失败可直接求职、科研助理过渡、来年再申请。
- 再申请设置 `phd_reapply`，材料经验增加，但面试会被问“上一年为什么没录”，通过率不应纯增加。

## 路由规则

- 八年制且未下车：本科结束直博。
- 5+3 且未下车：本科结束进入专硕/规培并轨。
- 推免成功或考研成功：本科结束进入硕士。
- 其余普通五年制：本科结束进入实习，再到规培/求职。
- 硕士毕业只有在 `phd_admitted`、未主动工作、未长学制下车时进入博士。
- 硕士未考博、考博失败、候补不等、长学制下车：进入求职。

## 毕业前半年冲突

升学和就业不能放在毕业之后才开始。现实中的申请、报名、面试、调剂、三方和导师确认都提前发生，天然挤占毕业论文、盲审、预答辩和正式答辩时间：

- 本科 `18-19` 季：毕业论文查重、答辩 PPT、实习出科、考研复试/调剂、规培报名、招聘投递同时出现。
- 硕士 `10-11` 季：硕士论文盲审、预答辩、正式答辩、考博材料、专业笔试、导师面试、医院招聘同时出现。
- 博士 `14-15` 季：博士论文送审、预答辩、学位会、论文返修、医院招聘和导师推荐同时出现。
- 选择“只顾升学/求职”会带来学位风险、声誉损失或心理/体力代价；选择“先保论文答辩”则可能错过复试、调剂或招聘窗口。

## 回归测试清单

- 大一大二不可出现正式考研、复试、调剂、出分事件。
- 考研链从大四下/大五上出现，且包含择校、初试、复试、调剂/失败出口。
- 六级通过能看到英语复试优势选项，未通过看不到该选项。
- 考研失败后存在调剂、直接就业/规培、二战三个出口。
- 二战标记会在后续面试中被消费。
- 普通考研上岸会把本科结束路由到硕士。
- 硕士毕业默认不再自动读博；必须有考博录取标记。
- 考博链包含医院/导师选择、材料审核、英语面试/研究计划、排名候补和失败出口。
- 打招呼/推荐信作为隐性加成存在，同时带来声誉或关系成本。
- 本科、硕士、博士毕业前半年必须有论文/答辩与考研、考博、求职窗口冲突事件；这些事件不能提前到低年级或阶段中段。
