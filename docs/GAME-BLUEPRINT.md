# FckMedCN · 游戏蓝图（设计师交接稿）

> 用途：供游戏设计师在现有实现基础上做**进一步的体验设计与优化升级**。
> 本文只描述"游戏现在是什么、由哪些系统构成、设计原则是什么、哪里还能打磨"，不重复代码细节。
> 数据现状：约 400+ 手写事件 + 约 5850 条程序化生成事件（含 400 条病房互访）、35 类患者画像、
> 65 个测试规格、src/data 约 10k 行。全量回归 **138 用例全绿**。

---

## 1. 一句话定位

**让高中生用一次完整的"人生模拟"体验一名医学生 / 医生从 18 岁到约 45 岁的路**——
不是经营游戏，也不是硬核医疗模拟，而是"有逻辑、能串联、贴近真实"的**叙事型人生模拟**。
核心卖点：早期的选择会在后来的阶段真实回响（"选择要回响"）。

## 2. 核心体验循环

```
        ┌──────────── 选择 ────────────┐
        │  （每张事件卡 2-4 个选项，     │
        │   选项带属性/金钱/关系变化    │
        │   与 flag 标记）              │
        └──────────────┬───────────────┘
                       ▼
        ┌──────────── 后果结算 ─────────┐
        │  sanity/money/reputation 等   │
        │  经济与心理随时间推进         │
        └──────────────┬───────────────┘
                       ▼
        ┌──────────── 跨阶段回响 ───────┐
        │  早期 flag 在后期以"回声事件"  │
        │  兑现（恩师/同学/旧伤/旧选择） │
        └──────────────┬───────────────┘
                       ▼
        ┌──────────── 结局 ────────────┐
        │  15+ 结局由真实状态(钱/婚姻/   │
        │  子女/职称/地区)判定，配真实   │
        │  数据对比                     │
        └──────────────────────────────┘
                       │
                       ▼
              多周目：图鉴 / 徽章 / 传承（永久开局加成）
```

**设计原则（已落地，设计师应保留）：**
- **选择要回响**：任何会设 flag 的选择，都应有消费者（回声事件 / 结局 / 徽章），无"死选择"。
- **不写处方/不武断诊断**：医疗内容只描述流程、风险沟通与上报路径，不给剂量、不给个体化诊断。
- **贴近真实**：数值（薪资、违约、地区差、报录比）经真实世界数据校准。

## 3. 生命周期阶段（叙事主线）

| 阶段 | 大致年龄 | 玩家主要命题 | 当前内容重点 |
|---|---|---|---|
| 高考 | 18 | 分数→选校/选专业/性别 | 放榜夜家庭情绪、梯队说明、承诺独白 |
| 本科 | 18-23 | 学业/人际/是否退学 | 白大衣/听诊器/考试焦虑/贷款/退学抉择 |
| 实习 | 23-24 | 第一次上临床 | 第一次被叫"医生"/OSCE/扎针/晕血 |
| 规培 | 24-27 | 独立值班前夜 | 首张处方/护士博弈/患者来信/考研冲突 |
| 硕博 | 23-30 | 科研/读博抉择 | 一作之争/论文压力/导师风格/出国联培 |
| 求职 | 27-30 | 投简历/面试/签约 | 7 机制写实管线（见 §4） |
| 职业 | 30-45 | 晋升/家庭/中年命题 | 主治→副高→正高、医患、家庭、倦怠 |
| 结局 | ~45 | 收尾 | 15+ 结局 + 真实数据对比 |

> 职业期 20 回合（约 3 年叙事），时间轴通过新闻 ticker 延伸到约 2044 年，防"后段断粮"。

## 4. 系统模块（设计师视角）

| 系统 | 作用 | 现状与可优化点 |
|---|---|---|
| **事件引擎** | 加权抽取 + 门控（stage/flag/属性/婚姻）+ 选项级门槛 + 后果弹窗 | 成熟。可考虑"动态难度"与"主题节奏曲线" |
| **属性系统** | 家境/成绩/运气/外貌 → 4 条成长线 | 已接后果链与多周目继承；属性在游戏内"成长"路径偏少 |
| **经济系统** | 地区/医院档位差异化薪资、房贷、资产、应急提现 | 已写实校准；可加"通胀/职业中期消费曲线" |
| **结局系统** | 15+ 结局 + 真实数据对比卡 | 丰富；可强化"玩家动机—结局"的引导 |
| **图鉴 / 徽章** | 跨周目收集（结局、22 个里程碑） | 留存钩子已建；可加"图鉴叙事化" |
| **多周目传承** | 点数经济 + 8 个永久开局 perk | 克制设计防高周目碾压；可扩 perk 维度 |
| **患者多样性** | 35 类真实画像 + 特质化交互 + 病房互访 | 池大；儿童/少年偏少、特质分布可更匀 |
| **诊断 / 用药 / 工作流链** | 检查→鉴别→复查、用药核对→升级、交接→会诊 | 流程正确（已医学复核）；偏"教学"，可更"戏剧化" |
| **求职写实管线** | 投简历(窗口/学历)、笔试、面试、单位选择(本校加成)、多 offer、违约赔钱、老板打招呼 | 7 机制齐全；可加"offer 谈判/薪资博弈"深度 |
| **新闻 ticker** | 真实世界时间锚点 | 已延伸到后段；可更贴合玩家选择 |
| **性别系统** | 开局可选，文案全量性别中立 | 已实现 |

## 5. 内容规模（量化）

- 手写事件：约 **400+**（分布在 本科/实习/规培/硕博/求职/职业/人生 多个文件）
- 程序化生成：约 **5850** 条（门诊/病房互访等按患者画像与阶段组合）
- 患者画像：**35** 类，覆盖 7 大人群，含 7 类交互特质
- 结局：**15+** 种；徽章：**22** 个；传承 perk：**8** 个
- 测试：**65** 个规格、**138** 用例全绿（含死 flag 回归、地区经济、事件池性能、平衡矩阵等防线）

## 6. 已落地的叙事/真实主义支柱（设计师应延续）

1. **学制/轨道串联**：临床 vs 科研事件由 degree/track 决定；院校 tier 接入叙事。
2. **选择后果链**：早期选择（规培/实习/本科埋下的 flag）在职业阶段兑现为回声事件。
3. **结局挂钩真实状态**：结局读真实 money/婚姻/子女，并展示"你 vs 真实数据"对比。
4. **地区经济**：一线三甲 vs 县城基层薪资约 1.9× 差异，购房档位分化。
5. **求职写实 7 机制**：时间窗口、学历门槛、笔试/面试淘汰率、本校附属加成、多 offer、违约赔钱+诚信档案、人情黑箱（老板打招呼）。
6. **学术线**：一作之争、破五唯临床型晋升通道、国自然申报季。
7. **家庭线**：值班错过家庭时刻、配偶怨言链、子女学医叙事。

## 7. 已知缺口 / 设计师可发力处

| 优先级 | 项 | 说明 | 设计价值 |
|---|---|---|---|
| 高 | **节奏与难度曲线** | 中段（规培/硕博）易疲惫，职业中期事件密但情绪起伏不足 | 全局心流曲线 |
| 高 | **新手引导（onboarding）** | 系统多，首局易"不知道在玩什么" | 降低劝退 |
| 中 | **急诊亚专科 / 时间轴重构** | 现有 4 亚专科(内/外/妇/儿)，缺急诊轮转机制 | 职业期结构更真实 |
| 中 | **患者画像医学复核** | 35 类画像的医学细节尚未逐条人工认证 | 真实主义闭环 |
| 中 | **诊断/用药链戏剧化** | 当前偏"带教教学"，可嵌入更具体的临床情境冲突 | 沉浸感 |
| 低 | **求职谈判深度** | offer 薪资/编制博弈可更深 | 经济策略性 |

## 8. 给设计师的优化建议方向（供讨论）

1. **情绪曲线设计**：把"高光时刻"（被患者认出、学生回来、正高公示）与"低谷"（倦怠、退培诱惑、家庭错过）
   按周目时间轴排布，避免中段平的。
2. **动机系统**：用"职业初心/家庭期待/经济压力"三股拉力做隐性目标，让 15 个结局各有"想要的玩家"。
3. **失败的安全网**：退培/转行/ burnout 已是结局，可加"二次机会"事件降低一局定终身的挫败。
4. **可教学性**：每阶段给一句"现实注脚"（现有 realDataCard 可前移为轻提示），边玩边科普。
5. **多周目叙事**：图鉴/徽章可带"老医生回忆录"式短篇，强化传承情感。
