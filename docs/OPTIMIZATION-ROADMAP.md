# 游戏蓝图回顾与优化任务清单

> 生成：2026-08-01（10 轮 big-picture / blueprint 级回顾）
> 方法：以"游戏原则（让高中生体验医生一生）"与"真实世界（医学教育/职称/收入/执业环境）"双向对接，逐系统核对现状 → 找偏差 → 列待办。关键数值已联网核对（职称晋升年限、年薪制试点收入）。
> 现状基线：全量 90 用例绿，tsc/build 绿（`npm run build` + `npx playwright test`）。

---

## Round 1 · 时间轴与生命周期

**现状**：81 个季度（2024Q3→2044Q3），年龄 18→45。本科 20 季、实习 5、规培 12、硕 12、博 16、求职 4、职业 12。叙事终点约 45 岁（`stable_at_45`）。

**与现实核对**：
- 真实：本科 5 年 + 规培 3 年 + 住院医 ~5 年 + 主治 5 年 + 副高 5 年 ≈ 23 年到正高（博士可 12-15 年）。游戏把"住院医→主治→副高→正高"压缩进职业期 3 年（叙事 42→45）——**压缩合理（游戏化），但晋升节奏过快**。
- 职业期只覆盖 3 年，无法展开"住院总医师""科室轮转""进修"等真实节点。

**待完善**：
- [ ] 职业期叙事延长到 5-6 年（MAX_TURNS 12→20），让"住院医→主治"过渡有独立阶段感
- [ ] 增加"住院总医师"（住院总）一年之灾：体力/心理双重压榨的固定剧情（第 1-2 年）
- [ ] 时间轴 UI：HUD 或简报显示"从医第 N 年"，强化岁月流逝感

---

## Round 2 · 医学教育路径（本科→规培→硕博）

**现状**：本科 20 季（5 年）→ 规培 12 季（3 年）→ 可选硕博；保研/考研分流；`track_clinical`/`track_research` 双轨。

**与现实核对**：
- 真实：临床医学 5 年制 + 规培并轨（专硕=规培，四证合一）；学硕重科研。游戏已体现"保研/考研/规培/硕博"主链路，方向正确。
- **缺失**：①"5+3 一体化"（专硕并轨规培）的选择叙事较弱；②规培结业考核（执医+结业考）只做了执医考试；③住院医师规范化培训结业证与执医证的双证逻辑未完全展开。

**待完善**：
- [ ] 规培中期增加"专硕并轨 vs 学硕"的再确认事件（当前本科已分流，规培期缺乏呼应）
- [ ] 增加"规培结业考核"事件链（执医考之后）：结业理论+技能，不过则影响执医注册
- [ ] 硕士阶段补"开题→中期→答辩"的完整学术链条（现有 m2 链，可补"中期考核危机"）

---

## Round 3 · 职称晋升体系

**现状**：职业期 12 季内"主治→副高→正高"三段晋升事件，用 flag 门控；结局按职称挂钩。

**与现实核对**：
- 真实：主治→副高需满 **5 年**、副高→正高 **5 年**；基层年限可缩但科研门槛升；近年评价向"临床实绩"倾斜（游戏 newsTickerAfter 已提）。
- 游戏把 15 年压缩进 3 年——**可接受，但缺"年限门槛"的具象化**（玩家体会不到"熬年限"）。

**待完善**：
- [ ] 晋升事件增加"年限资格"检查（如到副高需在职业期至少 N 季后），强化"熬"的体验
- [ ] 增加"申报材料被退回/差一分"的挫折事件（现实高频），副高/正高增加失败分支（当前只有一次机会）
- [ ] 结局页真实数据卡按职称刷新（主任医师 30 万/年、副主任 25 万、主治 20 万——年薪制试点口径）

---

## Round 4 · 收入与生活（经济系统）

**现状**：阶段固定收支 + 家境/导师/理财/资产/贷款；职业收入=底薪+职称档差+绩效；房贷/育儿；负债结局。

**与现实核对（联网）**：
- 年薪制试点：主任 ~30 万/年、副主任 ~25 万、主治 ~20 万；东部三甲主任 40-60 万（绩效占 60%+）。
- 游戏：主治 ~14.6 万/年、正高 ~17.6 万/年（按 rep30 估算）——**中级职称贴近现实下限，高级职称明显偏低**（正高比现实低 40-60%）。这是"游戏需要经济压力"与"真实高薪"的冲突，但结局"真实数据卡"用的是真实数字，会显得玩家被低估。

**待完善**：
- [ ] 提高高级职称档差（副高/正高收入上移，接近年薪制口径），用"绩效波动/科室效益"制造压力而非纯低收入
- [ ] 增加"科室效益/绩效季度波动"（现实：绩效占比 60%+，随科室营收波动）
- [ ] 房贷与房价对齐：当前首付 -8000、月供 2500/季，省会房价按 3-5 万/㎡ 应有更高首付与更长月供（或明确"小城市/租房"两条路）
- [ ] 增加"医疗耗材/带量采购""科室药品占比考核"等真实经济压力事件

---

## Round 5 · 医患关系与纠纷

**现状**：已有医闹、纠纷、诉状/仲裁（第 3/9 季强制）、请律师/私了/硬扛。

**与现实核对**：
- 真实：医疗损害责任纠纷走"医疗损害鉴定/司法鉴定"；举证责任倒置（医院举证）；诉讼周期长（1-3 年）。
- 游戏已覆盖"诉状/仲裁/私了/律师"，**结构成立**。缺：①诉讼结果的不确定性（鉴定结论随机）；②"举证责任"机制（病历/证据好坏影响胜负）；③心理创伤与职业倦怠的后续。

**待完善**：
- [ ] 诉讼事件增加"证据/病历质量"影响胜负的判定（病历扣费事件的结果可反哺诉讼结局）
- [ ] 增加"二审/再审"小概率追加（诉讼未了结的长期阴影）
- [ ] 增加"医患纠纷后的心理阴影"echo（reputation/sanity 长期影响）

---

## Round 6 · 执业环境与压力（亚专科/医保/DRG）

**现状**：医保拒付、DRG 按病种付费、亚专科劳累差异（外科体力/儿科心理）、职业初期压力差异化、夜班/抢救。

**与现实核对**：
- 真实：儿科/急诊/产科是"高离职、高压力"科室；DRG 全面铺开；医保基金监管（飞检）；多点执业放开。
- 游戏已有医保拒付/DRG/亚专科劳累/夜班。**缺**：①急诊科作为独立压力场景（当前只在轮转提及）；②"飞检/医保监管"事件；③职业暴露（针刺伤、院感）——真实高频且被忽视。

**待完善**：
- [ ] 增加"职业暴露"事件（针刺伤/呼吸道暴露）：感染风险 + 上报流程 + 心理阴影
- [ ] 增加"医保飞行检查/科室自查"事件（经济压力+合规叙事）
- [ ] 急诊科高压叙事：当前亚专科没有"急诊"，考虑加第 5 个选项或轮转机制
- [ ] 亚专科劳累应影响"可持续性"：外科高体力→长期降体力上限，儿科高心理→易触发危机（当前只改每季消耗）

## Round 7 · 学术与科研

**现状**：论文/国自然/学术不端（造假→被查/侥幸）/SCI 权重；硕博科研双轨。

**与现实核对**：
- 真实：论文在晋升中权重长期偏高、近年"破五唯"（唯论文/唯帽子）；国自然中标率 ~15-20%；撤稿/论文工厂真实存在。
- 游戏已覆盖论文/造假/国自然/撤稿。**缺**：①"破五唯"政策带来的"临床型晋升通道"（游戏结局 master_clinician 已提，但事件链弱）；②科研被"卷"的具体日常（数据被抢、一作之争）；③国自然申报季的仪式感。

**待完善**：
- [ ] 增加"一作/通讯之争"事件（同门抢一作、导师加名）——真实科研生态高频
- [ ] 增加"临床型晋升通道"事件（论文少但临床强也能评上）呼应"破五唯"
- [ ] 国自然申报做季节事件（每年固定季度触发，命中率按 papers/research 加权）

---

## Round 8 · 家庭、婚姻与社会

**现状**：婚姻/育儿/家人离世/恋爱（中性 ta）；性别称谓占位符；父母补贴。

**与现实核对**：
- 真实：医生群体"晚婚晚育"、离婚率不低、子女教育投入高；医二代/家庭期望。
- 游戏已有婚姻/育儿/家人。**缺**：①医生职业对婚姻/育儿的"时间挤压"专项（值班错过孩子成长、伴侣抱怨）；②"父母生病时你在手术台"的伦理两难（有 family_vs_duty 单点，可扩展）；③子女教育与医学生家庭传承。

**待完善**：
- [ ] 增加"值班错过家庭重要时刻"事件（结婚纪念/孩子家长会/父母生日）——高频现实痛点
- [ ] 增加"配偶职业冲突"（双职工/配偶怨言）事件链
- [ ] 增加"下一代"叙事：孩子长大选择是否学医（呼应"医一代"视角）

---

## Round 9 · 游戏机制与多周目

**现状**：开局性别+四点分配、随机家庭/导师、理财策略/资产、图鉴/徽章/传承、高考成绩=成绩属性定档、R 菜单、HUD 属性显示。

**待完善**：
- [ ] **属性成长缺失**：attrs 只在开局定死，游戏内无"属性成长"（家庭/外貌随人生变化？建议至少运气/外貌可被事件改变）
- [ ] **资产账户没有提现/用途**：资产只累积+计入结局，缺少"用资产做大事"（购房/创业/教育基金）的消耗口
- [ ] **多周目继承深度**：传承只加属性，可加"家族树/子女继承"（第 8 轮子代叙事 + 多周目）
- [ ] **图鉴触发提示**：图鉴收录只在结局页提示，游戏中解锁里程碑已有弹窗；可加"结局图鉴进度"在标题页 G 入口显示角标
- [ ] **难度曲线**：拮据家庭已加助学贷款，但科研轨/临床轨的难度差未验证（建议 balance-sim 增加按轨断言）

## Round 10 · 技术、测试与可维护性

**现状**：90 用例（经济/属性/事件/新闻/技能中心/性别/诉讼/亚专科……），tsc/build 绿。

**待完善**：
- [ ] **全生命周期经济回归按轨扩展**：balance-sim 增加"临床轨 vs 科研轨"最终存款/职称区间断言
- [ ] **事件权重审计扩展**：event-weight-config 补"强制事件（lawsuit/specialty）不占用随机池"的断言
- [ ] **多周目回归**：连续两次开局的图鉴/传承/随机性隔离验证（当前单局为主）
- [ ] **移动端**：评估结论为"底子好但三小游戏纯键盘"，暂缓；若做需先抽 `interactPressed()`（已记录口子）
- [ ] **A2 文字目视**：唯一人工项，建议按 known-issues 的 5 条试玩路径复查

## 优先级总表（建议执行顺序）

| 优先级 | 项目 | 理由 |
|---|---|---|
| P0 | Round4：高级职称收入上移 + 绩效季度波动 | 与"真实数据卡"直接冲突，玩家明显被低估 |
| P0 | Round6：职业暴露/针刺伤 + 医保飞检 | 真实高频且未覆盖，教育价值高 |
| P1 | Round3：晋升失败分支 + 年限门槛 | 强化"熬年限"的核心职业体验 |
| P1 | Round7：一作之争 + 临床型晋升通道 | 呼应破五唯，丰富科研生态 |
| P1 | Round5：诉讼结果不确定性（证据/病历反哺） | 让已建的诉讼系统有深度 |
| P2 | Round8：值班错过家庭 + 子女叙事 | 温情/共鸣向，粘性 |
| P2 | Round9：资产提现用途 + 属性成长 | 让现有系统闭环 |
| P2 | Round10：按轨经济回归 + 强制事件池断言 | 测试防线 |
| P3 | Round1：职业期延长 + 住院总 | 结构改造，风险大，最后做 |

> 验收基线沿用：`npx tsc --noEmit` + `npm run build` + `npx playwright test`（全量）。
